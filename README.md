## The entry

`main.ts` writes a single job title — the weirdest one I could think of — to `/output/entry.txt`:

> **Senior Vice President of Apologizing to Geese**

A grand corporate rank glued to one gloriously specific, absurd duty. It reads like a real job on a business card — and then the geese arrive.

## Run

```sh
node main.ts
```

It writes the title (45 characters, nothing else) to `/output/entry.txt`.
